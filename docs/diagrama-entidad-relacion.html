Notas Importantes

  • auth.users es la tabla de autenticación de Supabase (externa al esquema public)
  • user_roles es una tabla compuesta (PK: user_id + role) con ENUM: admin, student, instructor
  • inscripciones tiene restricción UNIQUE(alumno_id, taller_id) para evitar duplicados
  • asistencias tiene restricción UNIQUE(alumno_id, taller_id, fecha) para un registro por día
  • deuda_alumnos es una VISTA que calcula deuda basado en asistencias y costo_por_sesion
  • settings almacena configuración global del sistema (ej: costo_por_sesion = 25)
  • audit_log registra todas las acciones de administración para trazabilidad
  • El campo turno en profiles acepta: matutino | vespertino
  • El campo estado en asistencias acepta: presente | ausente | retardo | justificado
  • cambios_restantes controla el límite de 3 cambios de taller por ciclo escolar
